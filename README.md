# Website-skills

Agent skills for building **high-quality, stunning websites** — collected from skills.sh (Vercel official + top community authors: Emil Kowalski, Jakub Krehel, Meng To, Paul Bakaus, W. Shobson, Three.js, Tailwind).

**124 skills** covering: design review, React/Next.js performance, icons, themes, colors, gradients, effects, 3D/WebGL, animations, transitions, typography, layout, and UI polish.

## 🧭 How to Work (IMPORTANT)

### When the agent starts a task

1. **Read this README first** — pick the P0 skills for the task from the tables above.
2. **Load ONLY what the task needs** — never load all 124 skills at once. Context stays light, the agent stays fast.
3. **Work step by step** — follow the procedure below, never skip ahead.

### When `/learn` is invoked on this repo

The agent **must NOT install/read everything in one shot**. Do this:

1. **Inventory first** — list the skill folders, note the P0/P1/P2 ratings.
2. **Phase 1 — P0 skills**: install and review the ~20 P0 skills (`web-design-guidelines`, `impeccable`, `better-ui`, `vercel-react-best-practices`, `animate`, `animation-vocabulary`, `better-colors`, `better-typography`, ...). One at a time.
3. **Phase 2 — P1 skills**: proceed at a steady pace, a few at a time.
4. **Phase 3 — P2 skills**: only skim the list; install on demand, do not load their contents.
5. **Pause between phases** — report progress after each phase to keep the session from getting heavy.

**Step-by-step rule:** for each skill, read its `SKILL.md` first, then decide. Do not batch-read 10 SKILL.md files into context at once. One skill → one read → one decision.

## Installing into Hermes

### Option A — one-shot (recommended)

```
/learn https://github.com/vaferkhanom/Website-skills
```

### Option B — persistent source (tap)

```bash
hermes skills tap add vaferkhanom/Website-skills
hermes skills install vaferkhanom/Website-skills/<skill-name>
hermes skills update
```

### Option C — CLI install (other agents)

```bash
npx skills add vaferkhanom/Website-skills
```

## Layout

One folder per skill, each with `SKILL.md` (+ optional `rules/`, `references/`), plus `.skills-manifest.json`.
